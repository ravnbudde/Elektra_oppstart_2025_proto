# MQTT-broker

På Pi-en brukes Mosquitto som systemd-tjeneste. Installer den sammen med
poengtavlen fra `Bæret/` med `sudo bash install.sh`.
Se [samlet installasjon og drift](../README.md).

[`windows/`](windows/README.md) inneholder det tidligere Windows/Docker-oppsettet.
Det er et separat alternativ for lokal testing og brukes ikke av Pi-installasjonen.
